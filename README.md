# [marvin.henssler.me](https://marvin.henssler.me) - Frontend

Personal webpage for the Henßler family. Still in development.
This project was developed with [Angular CLI](https://github.com/angular/angular-cli) version 16.1.1.
Icons used are part of the free version of [Fontawesome](https://fontawesome.com/).

The website is hosted by GitHub Pages, available [here](https://marvin.henssler.me). The hosted site consists only of the Angular frontend, and the app is designed to work without a backend.

A compatible backend is optional and available in another repository if you want server-side event storage and API support: [github.com/Rexjurgoran/website](https://github.com/Rexjurgoran/website/). That backend can run as a container on [Docker Hub](https://hub.docker.com/repository/docker/rexjurgoran/website-backend/general).
